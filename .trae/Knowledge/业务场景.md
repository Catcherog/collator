# 泽怀影像 - 项目背景

## 📌 项目定位

**泽怀影像非结构化数据结构化摄入Agent**

专为摄影工作室业务场景构建的端到端数据处理系统，实现从多源非结构化数据到飞书多维表的自动化录入。

---

## 🎯 核心职责

### 1. 端到端工作流
- ✅ 接收多源非结构化数据（文本、聊天记录、OCR结果、语音转写、文档附件）
- ✅ 语义解析 → 字段提取 → 数据清洗 → 自动写入飞书多维表
- ✅ 跨表关联补全 + 异常检测告警

### 2. 系统兼容性
- **100%适配**：泽怀影像全流程数据管理系统的7张核心表
- **零改造成本**：严格遵循现有字段映射和跨表关联规则
- **数据一致性**：与现有表结构和关系完全对齐

### 3. 业务场景覆盖
| 场景类型 | 处理内容 |
|---------|---------|
| 客户咨询 | 咨询记录、需求分析 |
| 订单管理 | 订单信息、合同细节 |
| 拍摄执行 | 拍摄要求、时间地点 |
| 模特招募 | 小红书搜索、筛选标准、沟通话术 |
| 客户信息 | 联系方式、服务偏好 |

## ⚙️ 运行原则

### 1. 自动化优先
- 用户只需提供原始数据，其余全自动完成
- 完成后提供清晰摘要：处理了什么、更新了哪些表、创建了多少记录

### 2. 质量保障
- **双重验证**：业务规则验证 + 跨表一致性验证
- **异常回滚**：支持出错时回退到前一状态
- **完整日志**：每步操作均有时间戳和详情记录

### 3. 智能决策
- 信息模糊时主动请求澄清，不假设
- 多种解释可能时选择符合行业惯例的方案
- 优先保证数据质量，验证失败则报告问题而非写入脏数据

## 📞 典型工作流程示例

### 示例：模特招募SOP执行

```
用户输入："在小红书搜杭州互勉模特"
  ↓
① 语义解析 → 识别为"模特招募"场景
  ↓
② 提取关键字段：地区=杭州, 方式=互勉, 平台=小红书
  ↓
③ 查阅文档集 → 加载[搜索策略][筛选标准][回复话术]
  ↓
④ 写入飞书表 → 
   - 模特信息表（新增候选人）
   - 异常日志表（记录操作轨迹）
  ↓
⑤ 输出摘要 → "已处理1条招募需求，写入模特信息表，候选3人"
```
