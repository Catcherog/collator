> **用途**：AI 首次进入项目或需要理解项目全貌时必读

---

## 一、项目是什么

**collator** 是泽怀影像工作室的**非结构化数据结构化摄入Agent**，运行在 Trae IDE 中。

核心任务：接收任意渠道的原始数据（聊天记录、OCR结果、语音转写、文档附件等），自动解析、清洗、标准化后写入飞书多维表，实现端到端数据自动化。

## 三、文件分类映射规则

### 按类型决定存放位置

| 文件类型 | 存放目录 | 示例 |
|---------|---------|------|
| AI规则/配置 | `.trae/rules/` | `项目操作规则.md`、`_core.md` |
| AI知识/参考 | `.trae/Knowledge/` | `业务场景.md`、`项目总览.md` |
| AI技能 | `.trae/skills/<skill名>/` | `lark-base/SKILL.md` |
| 指南/教程 | `docs/guides/` | `agent-core-config.md` |
| 报告/记录 | `docs/reports/` | `Step4_*.md` |
| 标准流程 | `docs/sop/` | `模特招募SOP.md` |
| JSON配置 | `src/config/` | `batch1.json` |
| 可执行脚本 | `src/` | `.ps1`、`.py`、`.js` |
| 图片/媒体 | `public/` | `.png`、`.jpg`、`.mp4` |

### 判断流程

```
新文件/需要归档的文件
    ↓
是AI相关配置？ → .trae/（rules/knowledge/skills）
    ↓ 否
是可执行代码？ → src/
    ↓ 否
是JSON配置？ → src/config/
    ↓ 否
是文档/报告？ → docs/（guides/reports/sop）
    ↓ 否
是图片/媒体？ → public/
```

## 五、AI 工作流程

### 进入项目时的标准动作

1. **读取本文件**（`项目总览.md`）了解项目全貌
2. **读取** `业务场景.md` 理解业务背景和数据架构
3. **读取** `文档集索引.md` 了解外部文档资源
4. **调用** `lark-shared` skill 确认飞书API认证状态（新会话时）
5. **根据用户需求**调用对应 skill（lark-base/lark-doc/lark-drive 等）

### 数据摄入标准流程

```
用户提供原始数据
    ↓
① 语义解析 → 识别业务场景（咨询/订单/拍摄/模特/客户）
    ↓
② 查阅 docs/guides/data-parsing-templates.md → 按模板提取字段
    ↓
③ 查阅 docs/guides/business-rules-library.md → 五重约束校验
    ↓
④ 调用 lark-base skill → 写入飞书多维表
    ↓
⑤ 执行跨表联动 → 确保数据一致性
    ↓
⑥ 输出操作摘要 → 成功/失败状态 + 影响记录数 + 表格链接
```
