## 三、失败教训与技术坑点（Lessons Learned）

### 3.1 PowerShell语法陷阱 ❌→✅

#### 坑点1：命令连接符错误

**❌ 失败代码**：
```powershell
cd "path" && python script.py  # Linux/bash语法
```

**错误信息**：
```
标记"&"不是此版本中的有效语句分隔符
```

**✅ 正确写法**：
```powershell
cd "path"; python script.py  # PowerShell使用分号
```

**原理**：
- Bash/Zsh使用`&&`作为条件连接符
- PowerShell使用`;`作为简单命令分隔符
- PowerShell的条件执行使用`-and`或`if`语句

#### 坑点2：Here-String误解析

**❌ 失败代码**：
```powershell
lark-cli api PUT "/path" --data @"data.json"
```

**错误信息**：
```
here-string 标题后面和行尾之前不允许包含任何字符
```

**原因分析**：
- PowerShell中`@`符号后跟双引号会被识别为here-string开始符
- here-string要求`@"`必须独占一行，前后不能有其他字符
- CLI的`@file`语法恰好触发了这个规则

**✅ 解决方案**：
```powershell
# 方案A：通过Python subprocess调用（推荐）
subprocess.run(['npx', 'lark-cli', 'api', 'PUT', ..., '--data', '@file.json'])

# 方案B：使用转义或不同引号
lark-cli api PUT '/path' --data '@file.json'  # 单引号可能有效
```

#### 坑点3：JSON双引号被Shell拆分

**❌ 失败代码**：
```powershell
lark-cli sheets +write --values '[["col1","col2"]]'
```

**错误信息**：
```
positional arguments are not supported (got ["col2"])
```

**原因**：
- PowerShell将外层双引号内的内容拆分成多个参数
- 内部双引号被当作参数边界处理

**✅ 解决方案**：
- 完全避免在命令行中内联JSON
- 始终使用文件传递：`--data @data.json`

### 3.2 Python subprocess调用陷阱 ❌→✅

#### 坑点4：FileNotFoundError（找不到命令）

**❌ 失败代码**：
```python
import subprocess
result = subprocess.run(
    ['lark-cli', 'api', 'PUT', ...],  # 直接使用命令名
    ...
)
```

**错误信息**：
```
FileNotFoundError: [WinError 2] 系统找不到指定的文件。
```

**原因**：
- `lark-cli`是通过npm全局安装的（`npm install -g @larksuite/cli`）
- Windows下全局npm包的路径可能不在系统PATH中
- subprocess默认不继承完整的shell环境变量

**✅ 解决方案**：

```python
# 方案1：使用npx（最可靠）
cmd = ['npx', 'lark-cli', 'api', 'PUT', ...]
result = subprocess.run(cmd, shell=True, ...)

# 方案2：指定完整路径（需要先找到安装位置）
import shutil
lark_cli_path = shutil.which('lark-cli') or 'npx lark-cli'
result = subprocess.run([lark_cli_path, ...], shell=True, ...)
```

**最佳实践**：
- Windows环境下始终使用`shell=True` + `npx lark-cli`
- 或提前用`where lark-cli`/`which lark-cli`确认路径

#### 坑点5：shell=True的使用时机

**规则**：
| 场景 | 推荐方式 | 说明 |
|------|----------|------|
| 简单命令（无特殊字符） | `shell=False`, cmd为列表 | 安全性高 |
| 需要管道/重定向 | `shell=True`, cmd为字符串 | 必须用字符串 |
| 包含`@`/`&`等特殊字符 | `shell=True`, cmd为字符串 | 避免解析问题 |
| 调用npx/npm/node | `shell=True`, cmd为字符串 | 确保能找到命令 |

**示例对比**：
```python
# ❌ 错误：列表形式 + 特殊字符
subprocess.run(['lark-cli', 'api', 'PUT', '--data', '@file.json'], shell=False)

# ✅ 正确：字符串形式 + shell=True
subprocess.run('npx lark-cli api PUT --data @file.json', shell=True)
```

### 3.3 API参数设计陷阱 ❌→✅

#### 坑点6：Range范围硬编码导致截断

**❌ 失败配置**：
```json
{
  "valueRange": {
    "range": "2cf5ee!A1:J36",  // 硬编码36行
    "values": [...]  // 实际42行
  }
}
```

**错误信息**：
```json
{
  "code": 90202,
  "message": "range in request is wrong, rows of value:42 > range"
}
```

**原因**：
- 初始读取CSV时只看了前35条就假设总共36行
- 未动态计算实际数据量就设定了范围

**✅ 解决方案**：
```python
# 动态计算范围
total_rows = len(all_data)  # 包含表头的总行数
range_str = f'{sheet_id}!A1:J{total_rows}'

request_body = {
    'valueRange': {
        'range': range_str,
        'values': all_data
    }
}

print(f'Dynamic range: {range_str}')  # 输出日志便于调试
```

**防御性编程建议**：
```python
# 写入前校验
assert len(all_data) <= int(range_str.split('J')[1]), \
    f'Data rows ({len(all_data)}) exceeds range limit'
```

### 3.4 编码问题 ❌→✅

#### 坑点7：Windows GBK编码限制

**❌ 失败代码**：
```python
print('❌ 数据写入失败')  # Unicode emoji字符
```

**错误信息**：
```
UnicodeEncodeError: 'gbk' codec can't encode character '\u274c'
```

**原因**：
- Windows控制台默认编码为GBK（中文Windows系统）
- Emoji字符（❌✅📊等）不在GBK字符集中
- Python 3的print函数尝试用控制台编码输出

**✅ 解决方案**：

```python
# 方案1：使用ASCII替代字符
print('[FAILED] Data write failed')  # 避免emoji
print('[SUCCESS] Data written successfully!')

# 方案2：设置输出编码
import sys
sys.stdout.reconfigure(encoding='utf-8')  # Python 3.7+

# 方案3：异常捕获
try:
    print('✅ 成功')
except UnicodeEncodeError:
    print('[SUCCESS]')
```

**推荐做法**：
- 日志输出使用纯ASCII字符（[OK]/[FAIL]/[SUCCESS]等）
- 仅在用户界面显示时使用emoji
- 或在脚本开头统一设置UTF-8编码

## 四、标准化操作模板（SOP）

### 4.1 CSV导入飞书表格标准流程

基于本次经验，提炼出以下可复用的标准操作流程：

```python
"""
Standard Template: CSV to Feishu Sheet Import
Version: 1.0
Last Updated: 2026-05-13
"""

import csv
import json
import subprocess
import sys
import os

def csv_to_feishu_sheet(
    csv_file_path: str,
    spreadsheet_token: str,
    sheet_id: str,
    work_dir: str = None
) -> dict:
    """
    将CSV文件导入飞书电子表格
    
    Args:
        csv_file_path: CSV文件绝对路径
        spreadsheet_token: 飞书表格Token
        sheet_id: 工作表ID
        work_dir: 工作目录（用于存放临时文件）
    
    Returns:
        dict: API返回结果
    """
    
    # Step 1: 设置工作目录
    if work_dir:
        os.chdir(work_dir)
    
    # Step 2: 读取并解析CSV
    print(f'[INFO] Reading CSV file: {csv_file_path}')
    with open(csv_file_path, 'r', encoding='utf-8') as f:
        reader = csv.reader(f)
        headers = next(reader)
        data_rows = [row for row in reader]
    
    total_rows = len(data_rows) + 1  # +1 for header
    print(f'[INFO] Parsed {len(data_rows)} data rows + 1 header = {total_rows} total')
    
    # Step 3: 构建请求数据
    request_data = {
        'valueRange': {
            'range': f'{sheet_id}!A1:J{total_rows}',
            'values': [headers] + data_rows
        }
    }
    
    temp_json_file = 'temp_import_data.json'
    with open(temp_json_file, 'w', encoding='utf-8') as f:
        json.dump(request_data, f, ensure_ascii=False, indent=2)
    
    print(f'[INFO] Generated temporary JSON file: {temp_json_file}')
    
    # Step 4: 调用飞书API
    cmd = f'npx lark-cli api PUT "/open-apis/sheets/v2/spreadsheets/{spreadsheet_token}/values" --data @{temp_json_file}'
    
    print(f'[INFO] Executing Feishu API...')
    result = subprocess.run(
        cmd,
        shell=True,
        capture_output=True,
        text=True,
        encoding='utf-8'
    )
    
    # Step 5: 清理临时文件
    if os.path.exists(temp_json_file):
        os.unlink(temp_json_file)
        print(f'[INFO] Cleaned up temporary file: {temp_json_file}')
    
    # Step 6: 解析结果
    if result.returncode != 0:
        print(f'[ERROR] API call failed with code {result.returncode}')
        print(f'STDERR: {result.stderr[:500]}')
        sys.exit(1)
    
    try:
        output = json.loads(result.stdout)
        if output.get('code') == 0:
            d = output['data']
            print(f'[SUCCESS] Data import completed!')
            print(f'  - Updated Range: {d.get("updatedRange")}')
            print(f'  - Updated Rows: {d.get("updatedRows")}')
            print(f'  - Updated Columns: {d.get("updatedColumns")}')
            print(f'  - Updated Cells: {d.get("updatedCells")}')
            return output
        else:
            print(f'[ERROR] API returned error: {output}')
            sys.exit(1)
    except Exception as e:
        print(f'[WARNING] Could not parse response: {e}')
        print(f'Raw output: {result.stdout[:200]}')
        return {'raw_output': result.stdout}
```

```python
def clean_data(row, rules):
    """应用数据清洗规则"""
    cleaned = []
    for value, rule in zip(row, rules):
        if rule == 'strip':
            cleaned.append(str(value).strip())
        elif rule == 'remove_bom':
            cleaned.append(value.lstrip('\ufeff'))
        elif rule == 'default_empty':
            cleaned.append(value if value else 'N/A')
        else:
            cleaned.append(value)
    return cleaned
```
