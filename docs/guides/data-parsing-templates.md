> **版本**: V1.0

> **用途**: 为Agent提供标准化的数据解析流程和输出格式

## 一、数据源类型识别与分类

### 1.1 支持的数据源类型

| 数据源类型 | 典型来源 | 特征标识 | 复杂度 |
|-----------|---------|---------|--------|
| 纯文本 | 用户手动输入、邮件、表单 | 结构化或半结构化文本 | ⭐ 低 |
| 聊天记录 | 微信/QQ/飞书聊天导出 | 包含时间戳、发送者、对话流 | ⭐⭐ 中 |
| OCR结果 | 名片、合同、订单截图 | 可能包含识别错误、格式混乱 | ⭐⭐⭐ 高 |
| 语音转写 | 通话录音、语音备忘录 | 口语化表达、可能含语气词 | ⭐⭐⭐ 高 |
| 文档附件 | Word/PDF合同、Excel报价单 | 结构化程度高，但需解析文档 | ⭐⭐ 中 |
| 系统截图 | 后台订单页、CRM界面 | 视觉信息为主，需结合文字描述 | ⭐⭐⭐⭐ 极高 |

### 1.2 自动识别策略

当用户提交数据时，Agent应按以下顺序判断数据源类型：

```
用户输入数据
    ↓
是否包含图片/文件？ → 是 → OCR/文档解析模式
    ↓ 否
是否包含时间戳和对话标记？ → 是 → 聊天记录模式
    ↓ 否
是否包含口语化特征（嗯/啊/那个）？ → 是 → 语音转写模式
    ↓ 否
是否是长文本且有明确段落？ → 是 → 文档解析模式
    ↓ 否
→ 默认使用纯文本模式
```

  "parsed_data": {

    "operation": "create|update|batch_create",
    "primary_key_value": "主键值（如果已知）",
    "fields": {
      "系统字段名": {
        "value": "提取的值",
        "confidence": 0.95,
        "source_text": "原始文本片段",
        "notes": "备注说明"
      }
    },
    "relations": {
      "关联字段名": {

    "logic_consistency": "passed|warning|failed",
    "logic_warnings": ["逻辑警告列表"]
    }
  },
  "agent_actions": {
    "next_step": "confirm_with_user|auto_write|request_clarification|stop_and_report",

        "corrected_value": "修正后值",

### 2.2 字段置信度说明

`confidence` 字段表示Agent对提取结果的信心程度：

| 置信度范围 | 含义 | 处理策略 |
|-----------|------|---------|
| 0.9 - 1.0 | 高度确定，关键词精确匹配 | 可直接使用，无需确认 |
| 0.7 - 0.9 | 较确定，需要轻微推断 | 可自动应用但建议用户复核 |
| 0.5 - 0.7 | 不太确定，存在歧义 | 必须向用户确认后再使用 |
| < 0.5 | 高度不确定，可能错误 | 必须请求用户提供正确值 |

## 四、常见歧义消解规则

### 4.1 时间表达归一化

| 自然语言表达 | 归一化结果 | 示例 |
|------------|-----------|------|
| 今天 | 当天日期 | 2026-04-26 |
| 明天 | 当天+1天 | 2026-04-27 |
|后天 | 当天+2天 | 2026-04-28 |
| 下周/下周末 | 当天+7~9天 | 需进一步确认具体日期 |
| 这周末 | 本周六或周日 | 需进一步确认 |
| X月X日 | 具体日期 | 直接转换 |
| X号 | 当月X号 | 需补充月份 |
| 周X | 最近的一个周X | 计算具体日期 |
| 大概/左右/前后 | ±3天浮动范围 | 标记为近似值 |

### 4.2 金额表达归一化

| 自然语言表达 | 归一化规则 | 示例 |
|------------|-----------|------|
| 2000多 | 向上取整到区间 | 2000-3000元 |
| 两三千 | 区间估计 | 2000-3000元 |
| 几千 | 模糊估计 | 标记为"待确认" |
| 1k/2k | k=千 | 1000/2000元 |
| 包含单位 | 提取数字部分 | "1980起" → 1980 |

### 4.3 拍摄类型映射

| 用户表述 | 系统值 | 置信度 |
|---------|--------|--------|
| 宝宝照/儿童照/满月照/百天照/周岁照 | 亲子 | 0.98 |
| 个人写真/艺术照/形象照/模特约拍 | 创作片 | 0.95 |
| 产品拍摄/电商拍摄/形象广告/团队照 | 商业拍摄 | 0.95 |
| 婚纱照/婚礼跟拍 | 亲子 or 商业拍摄 | 0.7（需确认） |
| 全家福 | 亲子 | 0.95 |

### 4.4 风格同义词扩展
