# Trae 新窗口启动提示词

> 在 Trae 中新开窗口时复制以下提示词，引导 Trae 恢复完整项目上下文。
> Trae 读取的是本地工作区文件，使用前需确保已 `git pull` 与远程同步。

---

```text
请按照 AGENTS.md「必须读取的项目文件清单（按启动顺序）」恢复完整项目上下文：

1. 读取 AGENTS.md，确认项目当前阶段、GPT 与 Trae 的角色分工、当前任务位置、项目事实来源声明、基本执行规则。
2. 读取「改造方案.txt」，重点理解第 5 节（每次新窗口的启动流程）、第 6 节（任务包处理）、第 7 节（实现原则）、第 9 节（验证规则）、第 19 节（核心规则）。
3. 读取 docs/ai/PROJECT_STATE.md，确认当前产品阶段、当前里程碑、已完成内容、正在进行任务、下一优先级、已知风险、当前阻塞项。
4. 读取 docs/ai/REVIEW_POLICY.md，确认当前审查阶段、P0/P1/P2 定义、阻塞合并规则、GPT 复审范围、当前任务停止条件。
5. 读取 docs/ai/TRAE_COLLABORATION_GUIDE.md，确认 Phase 推进流程、Gate A-G 验收体系、验证命令清单。
6. 如果 PROJECT_STATE.md 中标注了当前活动任务，读取 docs/ai/tasks/ 下对应的 TASK-xxx.md。
7. 执行 Git 状态检查：
   - git status
   - git branch --show-current
   - git log -1 --oneline
   确认当前分支是否正确、是否存在未提交修改、当前代码是否与任务基线一致。

完成以上步骤后，请输出以下确认信息：
- 当前项目阶段
- 当前分支
- 是否存在未提交修改（如有，说明来源）
- 当前阻塞项

确认完成后，等待我提供任务包。在我给出任务包之前，不要开始修改任何文件。
```

---

**使用说明**：
- Trae 读取的是本地工作区文件，必须确保本地代码已与远程同步（`git pull`）。
- 如果发现未提交修改不属于当前任务，必须按改造方案第 7.4 节隔离，不得覆盖或混入。
- 此提示词对应改造方案第 5 节的完整启动流程。
